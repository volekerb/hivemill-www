Catalog/Plugins

Hivemill

Set up a self-hosted Hivemill factory with the guided installer.

When to use it

Install the factory on a fresh Debian or Ubuntu host with a logged-in Claude Code.

Requirements

A fresh Debian or Ubuntu host and a logged-in Claude Code. The installer guide documents the remaining dependencies.

Install

Run these commands in Claude Code.

Claude Code
/plugin marketplace add volekerb/hivemill
/plugin install hivemill@hivemill
