Overview

You reclaim disk space and remove clutter without ever losing work.

Worktrees and branches: `factory clean`

The judge squash-merges, so `git branch -d` refuses merged factory branches. `factory clean` does the removal with its safety checks built in (task done/cancelled, no live agent, PR merged/closed, worktree clean and inside `~/factory/worktrees/`, nothing unpushed, no agent or herdr pane with its cwd inside; `factory clean` exits 4 if herdr cannot be queried). Rows reading `nothing to remove` are already gone. 1. `factory clean --dry-run` and read the table. Every `would remove` row must make sense. Every `skip` row is left alone, and you report the reasons. 2. `factory clean`, then compare its output with the dry run. Prefer `factory clean`; never use `git worktree remove --force` or `rm -rf` on task worktrees. Directories reported as `orphan (left alone)` stay; mention them in your report.

Deleting a `factory/*` branch by hand

For a remote branch use `factory clean --remote-branch factory/<x> [--dry-run]` (checks and logs it; see docs/clean-remote-branch.md), never raw `git push --delete`. Local branches only, when `factory clean` does not cover the case (for example a proof branch). Delete `factory/<x>` locally with `git branch -D factory/<x>` only when ALL of these hold: 1. its task is `done` or `cancelled` (`factory task show <task>`); 2. its PR is `MERGED` or `CLOSED` (`gh pr view factory/<x> --json state`); 3. no worktree uses it (`git worktree list`). Every target must start with `factory/`. The guard refuses `main`, `state`, `:main`, any other prefix, globs, and a list where any one target is not `factory/*`; it also refuses every other `git push`.

Also safe to remove

- `/tmp/qa-*`, stale `~/factory/run/*.prompt.md` for agents with status exited or lost, package-manager caches only when disk is over 80% full.

Never

- Touch a worktree or branch of an agent that is `live` or `queued` (`factory agents`). - Delete unmerged work, or delete a branch that fails any of the three checks above. Merged remote branches are normally deleted by the judge's merge. - Touch anything outside `~/factory/worktrees`, project repos' factory branches and `/tmp`.

Finish

Report what you removed, how much space you reclaimed (`df -h ~` before and after), and anything suspicious you left alone: `factory done "…"`.
