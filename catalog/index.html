Skills

Skills ship inside plugins. Install the plugin that carries the skill.

agent-context-limits

Cap the context of worker agents on this machine (200k window, early compaction, short command and file output, no advisor calls) while one boss agent keeps the full 1M window, and add the token rules (blocking waits, logs to files, no acks) to the team's instructions.

Commands: hm-spend Plugin: hivemill-spend

Details Source: plugins/kit-spend/skills/agent-context-limits/SKILL.md

git clone --depth 1 https://github.com/volekerb/hivemill && claude --plugin-dir hivemill/plugins/kit-spend
