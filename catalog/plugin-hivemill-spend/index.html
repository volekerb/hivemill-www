hivemill-spend

See where your Claude tokens go across agents, and cap worker context while the boss keeps the big picture.

Install

git clone --depth 1 https://github.com/volekerb/hivemill && claude --plugin-dir hivemill/plugins/kit-spend

Includes

Commands: hm-spend

Combines with

  • agent-context-limits Cap the context of worker agents on this machine (200k window, early compaction, short command and file output, no advisor calls) while one boss agent keeps the full 1M window, and add the token rules (blocking waits, logs to files, no acks) to the team's instructions.
  • token-spend-audit Find out where Claude tokens go on this machine (cost by model, the most expensive agent sessions, oversized contexts, turns that do nothing, cache writes, Fable use) and what to change.
