Hivemill Spend

Inspect Claude token usage and configure worker context limits.

When to use it

Investigate costly sessions or reduce oversized worker contexts on a factory host.

Requirements

Claude Code and access to the local Claude session data you want to inspect.

Install

Run this command in your terminal to load the plugin in Claude Code.

Terminal
git clone --depth 1 https://github.com/volekerb/hivemill && claude --plugin-dir hivemill/plugins/kit-spend
